# ORBIT Roadmap

## Completed (Stages 1–7 — MVP)
- Canonical versioned model schema (`v1.0.0`) & SQLite persistence with immutable version snapshots
- Restricted Python 3.11 AST-allowlisted mathematical parser & independent validator
- Deterministic System Dynamics engine with pluggable Euler & RK4 solvers
- Server-side Gemini 4 Hydrogen scenario interpretation, clarification workflow, and evidence-grounded result analysis
- Interactive scientific UI: Landing Preview, Dashboard, Scenario Builder, Model Editor + Cytoscape Graph, Simulation Workspace + Playback Scrubber, Experiment Laboratory, Results & CSV/JSON/PDF Reports

## Planned (Stages 8–10)
- **Stage 8 — Advanced Analytics**: Sobol/One-at-a-Time sensitivity analysis, multi-parameter grid sweeps, and seeded Monte Carlo ensembles with explicitly documented quantile vs. confidence interval methods
- **Stage 9 — Spatial & Multi-Agent Adapters**: Implement `SimulationEngineAdapter` subclasses for Mesa agent-based models and optional React Three Fiber 3D spatial views
- **Stage 10 — Hardening & Packaging**: Expanded Pytest/Playwright CI suites, containerized deployment profiles, and community model registry templates
